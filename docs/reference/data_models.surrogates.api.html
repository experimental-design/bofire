SingleTaskGPSurrogate

data_models.surrogates.api.SingleTaskGPSurrogate()

Gaussian process assembled from a kernel, a mean and a likelihood, with its hyperparameters fitted to the data.

The kernel decides which experiments the model considers similar, the mean what it predicts far from any data, and the likelihood how much of the spread in the data it attributes to measurement noise. The default is BoTorch’s default single-task GP: an RBF kernel with a lengthscale per input and priors scaled to the number of inputs.

Single-task GP for continuous and categorical inputs, as BoTorch’s MixedSingleTaskGP builds it.

Categorical inputs without descriptor data are encoded as ordinal codes and compared by a Hamming kernel; all other inputs and the engineered features by an RBF kernel with the HVARFNER prior. The kernel is the sum of the two plus their product, each scaled; without other inputs, the scaled Hamming kernel.

Single-task GP that detects outliers and discounts them: BoTorch’s RobustRelevancePursuitSingleTaskGP, with the lengthscales bounded at 0.05 instead of 0.025.

The likelihood adds an extra noise variance for observations treated as outliers to the HVARFNER noise model. The kernel is an RBF kernel with the HVARFNER prior whose lengthscales are at least 0.05, so that the model cannot simply explain the outliers.

tanimoto
data_models.surrogates.api.SingleTaskGPSurrogate.tanimoto(
    inputs,
    outputs,
    fingerprints=None,
)

Single-task GP over molecular inputs, with the Tanimoto similarity of the molecules’ fingerprints as kernel.

Every input is a categorical whose categories have structure data; the similarities between all categories of an input are computed once. With one input the kernel is a scaled Tanimoto kernel. With several, it is the scaled product of one Tanimoto kernel per input: two points are similar if each of their molecules is. The THREESIX outputscale prior and the THREESIX likelihood are used.

For other combinations (a sum of the molecules’ kernels, different fingerprints per molecule, further continuous inputs) build the kernel from TanimotoKernels directly.

MultiTaskGPSurrogate

data_models.surrogates.api.MultiTaskGPSurrogate()

Gaussian process over several related tasks, which learns how strongly they are correlated and transfers what it learns about one task to the others.

The tasks are the categories of the one CategoricalTaskInput, e.g. a cheap simulation and the real experiment, or a previous and the current campaign. The covariance is the kernel over the other inputs times a learned correlation between the tasks (intrinsic coregionalization). By default every task has a mean and a noise level of its own, so tasks may differ in offset and in measurement precision; with a plain mean or Gaussian likelihood, all tasks share one. Predictions for a task use the data of all tasks, weighted by how strongly they correlate with it.

Examples

>>> MultiTaskGPSurrogate(
...     inputs=Inputs(features=[
...         ContinuousInput(key="x", bounds=(0, 1)),
...         CategoricalTaskInput(key="task", categories=["simulation", "experiment"]),
...     ]),
...     outputs=Outputs(features=[ContinuousOutput(key="y")]),
... )

RandomForestSurrogate

data_models.surrogates.api.RandomForestSurrogate()

Random forest regressor: an average over many decision trees, each fitted to a random resample of the data.

The spread of the individual trees’ predictions serves as the uncertainty. The model assumes neither a smooth response nor a characteristic lengthscale, so it copes with abrupt changes and with responses that vary on different scales in different regions. It can’t extrapolate beyond the data, and its uncertainty is a heuristic, unlike the analytic uncertainty of a Gaussian process. The hyperparameters are those of scikit-learn’s RandomForestRegressor, with its defaults.

Examples

>>> RandomForestSurrogate(inputs=inputs, outputs=outputs, n_estimators=200)

MLPEnsemble

data_models.surrogates.api.MLPEnsemble()

Ensemble of small neural networks (multilayer perceptrons).

Every network is trained on a resample of the experiments drawn with replacement; predictions average over the networks, and their spread serves as the uncertainty. Suited to larger data sets than a Gaussian process.

SelectionSurrogate

data_models.surrogates.api.SelectionSurrogate()

Surrogate that chooses one of several complete surrogates by cross-validation.

When fitted, every option is cross-validated on the data, and the one with the best score in metric is fitted on all of the data and makes the predictions. Every option has the inputs and the single continuous output of this surrogate.

Examples

>>> SelectionSurrogate(
...     inputs=inputs,
...     outputs=outputs,
...     options=SingleTaskGPSurrogate.options(inputs, outputs),
... )

LBFGSB

data_models.surrogates.api.LBFGSB()

L-BFGS-B, the optimizer that fits a Gaussian process’s hyperparameters by maximizing the marginal likelihood.

Options left at None keep BoTorch’s defaults: scipy’s for an ordinary fit, and its own (at most 10000 iterations, tolerances of 1e-8) for the relevance pursuit of a GP with a SparseOutlierGaussianLikelihood.

Examples

>>> LBFGSB(maxiter=200)

BotorchSurrogates

data_models.surrogates.api.BotorchSurrogates()

The surrogates of a BoTorch strategy, one per output.

Each surrogate predicts one output; together they cover every output of the domain exactly once and use every input of the domain.

##### tanimoto { #bofire.data_models.surrogates.api.SingleTaskGPSurrogate.tanimoto }

```python
data_models.surrogates.api.SingleTaskGPSurrogate.tanimoto(
    inputs,
    outputs,
    fingerprints=None,
)
```

Single-task GP over molecular inputs, with the Tanimoto similarity of the
molecules' fingerprints as kernel.

Every input is a categorical whose categories have structure data; the
similarities between all categories of an input are computed once. With one
input the kernel is a scaled Tanimoto kernel. With several, it is the scaled
product of one Tanimoto kernel per input: two points are similar if each of
their molecules is. The THREESIX outputscale prior and the THREESIX likelihood
are used.

For other combinations (a sum of the molecules' kernels, different
fingerprints per molecule, further continuous inputs) build the kernel from
`TanimotoKernel`s directly.

###### Parameters {.doc-section .doc-section-parameters}

| Name         | Type                           | Description                                                                                                                         | Default    |
|--------------|--------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|------------|
| inputs       | Inputs                         | The input features: one or more categoricals with structure data.                                                                   | _required_ |
| outputs      | Outputs                        | The output feature.                                                                                                                 | _required_ |
| fingerprints | Optional\[DescriptorEncoding\] | How the fingerprints are computed from the structures, the same for every input. If not provided, Morgan fingerprints of 2048 bits. | `None`     |

| Name   | Type                  | Description    |
|--------|-----------------------|----------------|
|        | SingleTaskGPSurrogate | The surrogate. |

|--------|------------|-------------------------------------------------------|

### MultiTaskGPSurrogate { #bofire.data_models.surrogates.api.MultiTaskGPSurrogate }

```python
data_models.surrogates.api.MultiTaskGPSurrogate()
```

Gaussian process over several related tasks, which learns how strongly they are
correlated and transfers what it learns about one task to the others.

The tasks are the categories of the one `CategoricalTaskInput`, e.g. a cheap
simulation and the real experiment, or a previous and the current campaign. The
covariance is the kernel over the other inputs times a learned correlation between
the tasks (intrinsic coregionalization). By default every task has a mean and a
noise level of its own, so tasks may differ in offset and in measurement
precision; with a plain mean or Gaussian likelihood, all tasks share one.
Predictions for a task use the data of all tasks, weighted by how strongly they
correlate with it.

#### Examples {.doc-section .doc-section-examples}

```python
>>> MultiTaskGPSurrogate(
...     inputs=Inputs(features=[
...         ContinuousInput(key="x", bounds=(0, 1)),
...         CategoricalTaskInput(key="task", categories=["simulation", "experiment"]),
...     ]),
...     outputs=Outputs(features=[ContinuousOutput(key="y")]),
... )
```

### RandomForestSurrogate { #bofire.data_models.surrogates.api.RandomForestSurrogate }

```python
data_models.surrogates.api.RandomForestSurrogate()
```

Random forest regressor: an average over many decision trees, each fitted to a
random resample of the data.

The spread of the individual trees' predictions serves as the uncertainty. The
model assumes neither a smooth response nor a characteristic lengthscale, so it
copes with abrupt changes and with responses that vary on different scales in
different regions. It can't extrapolate beyond the data, and its uncertainty is
a heuristic, unlike the analytic uncertainty of a Gaussian process. The
hyperparameters are those of
scikit-learn's `RandomForestRegressor`, with its defaults.

#### Examples {.doc-section .doc-section-examples}

```python
>>> RandomForestSurrogate(inputs=inputs, outputs=outputs, n_estimators=200)
```

### MLPEnsemble { #bofire.data_models.surrogates.api.MLPEnsemble }

```python

```

Ensemble of small neural networks (multilayer perceptrons).

Every network is trained on a resample of the experiments drawn with
replacement; predictions average over the networks, and their spread serves as
the uncertainty. Suited to larger data sets than a Gaussian process.

### SelectionSurrogate { #bofire.data_models.surrogates.api.SelectionSurrogate }

```python

Surrogate that chooses one of several complete surrogates by cross-validation.

When fitted, every option is cross-validated on the data, and the one with the
best score in `metric` is fitted on all of the data and makes the predictions.
Every option has the inputs and the single continuous output of this surrogate.

### LBFGSB { #bofire.data_models.surrogates.api.LBFGSB }

```

L-BFGS-B, the optimizer that fits a Gaussian process's hyperparameters by
maximizing the marginal likelihood.

Options left at None keep BoTorch's defaults: scipy's for an ordinary fit, and
its own (at most 10000 iterations, tolerances of 1e-8) for the relevance pursuit
of a GP with a `SparseOutlierGaussianLikelihood`.
